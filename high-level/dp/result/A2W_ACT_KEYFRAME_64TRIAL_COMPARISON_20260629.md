# A2W ACT 关键帧训练对比评测（2026-06-29）

## 1. 评测目的

对比同一份 A2W WC4 数据集上训练的两类 ACT：

- `keyframe30k` / `keyframe50k`：关键帧窗口权重 8、半径 3，关键帧采样比例 20%，启用 `loss.action_weight`。
- `baseline50k`：不使用关键帧重采样，不使用关键帧 action loss 权重。

本次关键帧模型没有启用 camera input gating，因此主要变量是关键帧采样与 loss 加权。

## 2. 评测设置

- 每个 checkpoint × horizon 评测 64 次，共 12 组、768 次 rollout。
- 每次 16 个并行环境，共 4 批；批 seed 为 `62000` 至 `62003`。
- 每个环境通过 `SeedSequence([batch_seed, env_index])` 得到独立环境 seed，共 64 个不同随机配置。
- action horizon：`10, 12, 14, 15`。
- 每次 1000 steps，WC4 门，开门角绝对值达到 80° 判定成功。
- 开启环境随机化和相机位姿随机化：位置 ±0.02 m、旋转 ±5°。
- 不加 depth noise，不加 Gaussian blur，深度裁剪 0.2–1.5 m。
- 所有模型使用完全相同的 seed、环境参数和成功判据。

这里的夹爪重开定义为：首次完全闭合前，command 先高于 `-1.1`，随后退回低于 `-1.4`，之后再次高于 `-1.1`。

H9、H11、H14 的成功率并列最高；H9 的夹爪重开次数明显更少，因此 H9 是该 checkpoint 当前更好的成功率/动作平滑性折中。H9 与 H14 在相同 64 个随机环境中的配对结果为：共同成功 23、H9 独占成功 6、H14 独占成功 6、共同失败 29。

各最佳配置的 Wilson 95% 置信区间：

- Keyframe 30k / H14：48.44%，95% CI `[36.6%, 60.4%]`
- Keyframe 50k / H14：45.31%，95% CI `[33.7%, 57.4%]`
- Baseline 50k / H15：65.62%，95% CI `[53.4%, 76.1%]`

## 4. 配对比较

同一 horizon、同一组 64 个环境随机配置：

- Keyframe 50k / H14 对 Baseline 50k / H14：
  - 关键帧模型 29/64，baseline 36/64，下降 10.94 个百分点。
  - 关键帧独占成功 6 次，baseline 独占成功 13 次。
  - exact McNemar `p=0.167`，64 次样本下尚未达到显著差异。
- Keyframe 50k / H15 对 Baseline 50k / H15：
  - 关键帧模型 25/64，baseline 42/64，下降 26.56 个百分点。
  - 关键帧独占成功 3 次，baseline 独占成功 20 次。
  - exact McNemar `p=0.00049`，差异明显。

比较各模型在本次 sweep 中选出的最佳 horizon：

- Keyframe 50k / H14：29/64（45.31%）
- Baseline 50k / H15：42/64（65.62%）
- 差值：关键帧模型低 20.31 个百分点。
- 同随机配置配对：关键帧独占成功 4 次，baseline 独占成功 17 次，探索性 McNemar `p=0.0072`。

由于最佳 horizon 是在这批测试结果上选出的，最后一项 p 值只能作为探索性证据；严格确认应使用另一批未参与选参的 seed。

## 5. 结论与原因分析

当前 `weight=8 + radius=3 + keyframe sampling=20%` 没有提升闭环开门成功率，反而低于原始 baseline。相同步数下，Keyframe 50k 的最佳值为 45.31%（H9/H11/H14 并列），Baseline 50k 为 65.62%。

可能的主要原因是关键帧监督强度偏大：

- 数据集共有 50,000 帧，其中 9,408 帧位于关键帧窗口，占 18.82%。因此 20% 重采样本身与数据天然比例接近，分布变化并不大。
- 但关键帧样本的 loss 权重为 8。按 20% 关键帧采样估算，关键帧在归一化加权 action loss 中贡献的期望权重约为：

  `0.2 × 8 / (0.2 × 8 + 0.8 × 1) = 66.7%`

- 也就是说，约 20% 的 batch anchor 承担了约三分之二的 action loss 压力。模型可能更贴合短暂的 grasp/rotate 邻域，却损失了接近、阶段衔接、持续推门等完整闭环行为的稳定性。
- Keyframe 30k 最佳结果略高于 Keyframe 50k（31 对 29），但配对 McNemar `p=0.815`，不能认为 30k 真正优于 50k；它至少说明继续训练到 50k 没有带来可见提升。
- Keyframe 30k 在 H14 最好；Keyframe 50k 在 H9/H11/H14 并列最好，baseline 在 H15 最好。这说明训练目标改变后，策略的时序误差和可稳定执行的 open-loop 长度也发生了变化。

## 6. 下一步建议

优先做单变量消融，避免同时改变采样与 loss：

1. 保留 20% 关键帧采样，但关闭 action loss 加权。
2. 保留 action loss 加权，但把权重从 8 降到 2 或 4，并关闭重采样。
3. 每组先用 H12、H14、H15 做 64 次筛选，再用新的 64 个 seed 复测最佳配置。

当前证据不支持直接采用 `sample=20% + weight=8` 作为最终训练方案。
